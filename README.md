# Build Forge 🔨

Random Build Generator for Elden Ring, Dark Souls 1-3, Bloodborne & Cyberpunk 2077.

157 builds với guide 3 phase (đầu→giữa→cuối+DLC), item path, affinity comparison, tips & tricks. Song ngữ Anh-Việt.

## Features
- 🎲 Random build per game (hoặc toàn bộ)
- 🎯 Filter: PVE / PVP / META / Meme / Trend / DLC
- 📖 Guide chi tiết từ đầu game đến cuối
- ⚔️ Affinity/gem comparison
- 🎒 Item locations + ảnh từ wiki
- 🌐 Song ngữ EN/VI
- 🎨 3D tilt cards + parallax + animations
- 🖤 Dark theme (gothic/premium)

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
npm start
```

## Deploy

**Recommended:** Deploy on [Vercel](https://vercel.com) (supports API routes + i18n).

```bash
npm install -g vercel
vercel
```

Or push to GitHub and enable Vercel/GitHub Pages integration.
